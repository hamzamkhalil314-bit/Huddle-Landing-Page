# Huddle Landing Page

A responsive landing page built as part of a Frontend Mentor challenge. This project focuses on creating a clean, modern UI using HTML and CSS while practicing responsive web design.

## 🚀 Live Demo

https://your-live-demo-link.com

## ✨ Features

- Responsive design for desktop and mobile devices
- Modern and clean user interface
- Flexbox layout
- Responsive typography
- Hover effects on buttons and social icons
- Google Fonts integration
- SVG illustrations and icons

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- Media Queries
- Google Fonts
